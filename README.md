# Flood Segmentation

A computer vision project for **flood-area segmentation from video**, implemented as a Jupyter Notebook for video inference.

## Features

* **Video-based flood segmentation** for identifying flooded regions across video frames.
* **Frame-level inference** for processing video input.
* Notebook-based workflow for experimenting with and running the segmentation pipeline.
* Supports visual analysis of segmentation results across video sequences.

## Tech Stack

**Python · Jupyter Notebook · Computer Vision**

## Project Structure

```text
flood-segmentation/
├── README.md
└── DIP_VIDEO_INFERENCE.ipynb
```

## Run

Install Jupyter Notebook and the dependencies required by the notebook, then open:

```bash
jupyter notebook DIP_VIDEO_INFERENCE.ipynb
```

Run the notebook cells sequentially to perform video inference.

## Notebook

`DIP_VIDEO_INFERENCE.ipynb` contains the video inference workflow for flood segmentation.
